# MVP Desenvolvimento FullStack FrontEnd Avançado

## Catálogo de jogos
Aplicação simples para demonstrar um catálogo de jogos e suas informações

### Requisitos

Para execução do projeto é necessário instalar o Node
[Node Download](https://nodejs.org/pt-br/download)
 Após instalação verifique se o npm e o node estão devidamente instalados
 execute 
 ```
 node -v
```
 ```
 npm -v 
```
Caso os dois comandos retornem a versão instaladas pode avançar para o próximo passo
### Como executar

Para executar o projeto primeiro navegue em um terminal até a pasta game-catalog e então execute 

```
npm install
```
após a instalação das bibliotecas necessárias execute 

```
npm run dev
```
O projeto iniciará automaticamente e estará disponivél na url
http://localhost:5173/
